# Number Guessing Game

A simple number guessing game developed in C during my first year of Computer Engineering at EMSI.

 🎮 About the Game

The computer randomly generates a number between 1 and 100.
The player tries to guess the generated number.
After each attempt, the program gives a clue about the range containing the number.
The game continues until the player finds the correct number.

 📚 Concepts Used

- Variables and Data Types
- Conditions ( 'if' , 'else if' , 'else' )
- Loops ('do while')
- User Input
- Random Numbers
- rand()
- srand()
- time()
- Score Management
- Input Validation

🛠️ Technologies

- C
- GCC
- Visual Studio Code

 🎯 Objective

The objective of this project was to practice C programming fundamentals, random number generation, loops, conditions, and user input through a simple interactive game.
